### 遇到的问题与处理

1. **overall.md 摘引首检 9 处不匹配**：我把 Java 代码缩进拍平到顶格、client.py 尾段缩进层级写错、一处签名被我压缩改写。全部改为保留源文件真实缩进/原文后复检通过。教训：给"人读"的代码摘引也不许手改格式，省略只能用显式 `...` 标记。
2. **环境大变（上会话的 uv 与 Python 3.13 消失）**：从零重装。pip 一律 "versions: none"——排查：curl 通、索引页正常、`pip --log` 显示索引页被当零链接 → 根因是 **Windows 注册表系统代理（127.0.0.1:9674）被 pip 自动读取且该代理 403 清华源**，`env -u` 与 `--proxy ""` 均无效，`NO_PROXY='*'` 解决。已写入 PROGRESS 环境备忘。
3. **gradlew build 36 分钟**：本工作副本首次构建（daemon 冷启 + 依赖解析），通过：BUILD SUCCESSFUL + smoke 45/45。
