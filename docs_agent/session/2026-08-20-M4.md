# 2026-08-20 会话（第三轮）：M4 反射层（等级框架 + L0/L1，记忆与认知接口后置）

## Plan + Spec（已与用户确认）

### 范围裁决

- 用户裁决：本轮只做基础反射层，**不做任何记忆/危险记忆/认知接口**（NEKO 模式待执行器层级成型后接入）
- 等级体系：L0 观察者 / L1 自保（默认）/ L2 自卫（**框架预留枚举位，实现后置独立轮次**——客户端战斗模块是最难件）；等级为严格单调能力束（Numen 删空闸教训：不做每条反射的开关）；升攻击等级人类-only
- 已采纳推荐：死亡=等玩家指令；危怪=纯逃离不还击（与"禁止攻击"约束一致）；撤离时显式 #stop
- L0 关动作不关感知：危险事件照常上报认知层，脊髓不接管

### 设计核心（三份精读报告的移植清单）

**调度器**（Numen CompanionBrain 的 asyncio 移植）：
- 0.5s 轮询协程，按注册序问 `can_run`，首个 True 胜出；层内单候选结构性消灭比较
- 打断级别三档（真客户端多输入共存优势）：`none`（旁路按键）/ `cooperative`（短暂接管归还）/ `preempt`（经 AgentLoop 掀翻当前任务）
- 边沿自持：每条反射内部管理触发状态/窗口/冷却；轮询为主，CRITICAL 事件（M2-B）只作加速器
- 先归位再宣布：反射结束后才注入知会消息

**反射基类**：
```python
class ReflexChain(Protocol):
    id: str; level: ReflexLevel; interrupt: Literal["none","cooperative","preempt"]
    def can_run(self, s: BodyState) -> bool: ...
    async def act(self, s: BodyState) -> None: ...
```

**L1 七条反射**（触发阈值全部来自精读实测值）：

| 反射 | 触发 | 动作 | 级别 |
|---|---|---|---|
| 换气 breath | 眼在水中且 air≤240/300 | 按住 SPACE 上浮；封顶找不到透气口立刻上报 | cooperative |
| 脱困 unstuck | 40tick 窗口有输入但位移<0.75 格 | yaw+137° 扇形爆发+周期跳 | cooperative |
| 撤离 fire | CRITICAL fire | #stop → 20 格找水优先否则反向撤 5 格 | preempt |
| 低血 health_low | CRITICAL health_low | 停任务+聊天上报 | preempt |
| 死亡 death | CRITICAL death | 上报带死亡坐标，等玩家指令（不自动重生） | preempt |
| 危怪 flee | 12 格内敌对怪进入危险半径（碰撞箱推攻击距离） | 反向逃离+上报，不还击 | preempt |
| 注视 speaking_look | 正在播报且主人 16 格内 | lookAt 主人（平滑转头） | none |

**等级框架**：
- `ReflexLevel` 枚举：observer(L0)/self_preserve(L1)/guard(L2 预留)
- 切换：聊天命令（如"反射等级 观察/自保"），人类-only（不进 VLM 工具表）；持久化到配置
- `<instincts>` 系统提示节按等级动态生成——等级是代码层与认知层唯一同步点（L2 攻击等级需同步修订安全约束，本轮只写框架注释）

**事后知会（非记忆）**：反射动作追加单行 behavior_log，下一轮 VLM 调用前 flush（尾部 500 字符）；death/低血走 urgent 立即注入。无持久化、无证据、无检索——纯消息

#### 核心内容（落地形态）

- **调度器**：`ReflexScheduler.run()` 常驻协程——采样身体（getStats 2Hz + air<300 才查眼位水 + 每秒实体采样）→ 按注册序问 `can_run`（death → health_low → fire → flee → breath → unstuck → speaking_look），**首个 True 胜出并 break**（层内单候选）；等级门控在调度循环（L0 七条全跳过），danger 事件 handler 不门控（〔危险〕行照进认知——关动作不关感知）。
- **三档打断**：`none`（speaking_look 旁路转头）/ `cooperative`（breath/unstuck 短暂接管按键后归还，任务不停）/ `preempt`（fire/flee/health_low/death 经 `request_preempt` 掀翻当前任务，end_reason=preempt、不播报——反射自己上报）。
- **等级框架**：`ReflexLevel` 严格单调能力束（L0 ⊂ L1 ⊂ L2，无每条反射开关——Numen 删空闸教训）；切换=聊天"反射等级 观察/自保"（人类-only，不进 VLM 工具表，`_on_chat` 识别即切换）；只改内存不持久化；`instincts_section(level)` 是代码层与认知层唯一同步点。
- **事后知会（非记忆）**：反射动作结束才写 behavior_log（先归位再宣布）；每轮 VLM 调用前 `_inject_reflex_notices` 替换式注入一条〔本能反应〕（尾 500 字符）；death/低血走 `inject_urgent` 排队 → 下次调用前/任务开头 drain 成〔紧急〕（任务死了自动留给下一任务——真机死亡场景正需要）。

#### 遇到的问题与处理

1. **死亡时其余反射不动作（真机暴露的产品缺陷，已修）**：溺死的尸体还会按 SPACE 刷了 18 次换气简报——breath/unstuck/flee/speaking_look 全部加 `not s.dead` 门控；修复后 28 用例重跑全绿。
2. **偏差 ①订阅不带 min_level**：bridge 订阅是单槽替换语义（第二次 subscribe 覆盖第一次），分两次订阅会让 chat（INFO）被 CRITICAL 过滤掉——改为一次订阅全类型 `["chat","death","fire","health_low","drown"]`，危险判定靠事件类型本身。
3. **偏差 ②entities 加 width（超出 spec T1 字面）**：flee 危险半径公式（width/2+1.5）brain 侧需要 width 输入；与 category 同为纯增字段，协议不动 1.2。
4. **偏差 ③等级切换真机非端到端**：单机无第二玩家，bot 自己的 chat 被自回显过滤——命令解析由单测覆盖，切换执行路径（`_apply_reflex_level` 播报/等级变更/后续生效）真机验证；多人端到端留下一轮。
5. **运维坑**：游戏窗口最小化时 `getScreenWidth()=0` → mouseMove 全废，PowerShell `ShowWindow(SW_RESTORE)` 恢复；新 jar 重启的启动命令从进程 WMI 提取，令牌只落 `%TEMP%\m4_restart\` 且**已删**。
6. **眼在水中信号**：getStats 无水/火/朝向字段（schema v1.2 实测）——air<300 时 world.query 查眼位方块，truncated 时保守为 True（M3.5 T5a 教训）。
