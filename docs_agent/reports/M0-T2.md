## 关键决策与理由

- 剧本驱动而非硬编码：大脑测试需要复现失败/超时/乱序等真游戏里难造的场景——剧本里都是一等公民
- 错误码对齐 JSON-RPC：-32700 解析 / -32600 未知帧 / -32601 未知方法 / -32602 参数不过 Schema；真 Mod（M1-B）沿用了同一套
- 不 mock websockets 库本身：测试起真实服务器 + 真实客户端回环

## 实现要点

- 分发按 JSON 的 `type` 字段路由（request/task/hello→不支持）——**hello 会回 -32600，客户端按"身体不支持握手"降级处理（M1-D 依赖此行为）**
- 未编排的工具调用回通用成功；多任务乱序完成靠 task_id 归属（有专门测试）
