## 关键决策与理由

- 每模型 docstring 标注规格出处（"spec §8.2"等）——模型与规格可互查
- id 字段用 str（uuid）：与 JSON-RPC 兼容且防 Python int/str 混用
- `interrupt_policy` 枚举不含 pause：规格 §8.4 已取消 PAUSE，模型层直接拒绝

## 实现要点

- 请求帧默认 `type:"request"`，但**帧分发方（mock/Mod）按 JSON 原始 type 字段路由**——构造裸 dict 时必须显式带 type
- capability 响应结构：`{type:"response", id, result: [Capability], protocol_version}`——result 直接是列表，不是嵌套对象（曾让验收脚本踩坑）
